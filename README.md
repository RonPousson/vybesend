# VybeSend Audience

Internal-only VybeMedia campaign management platform.

## Current milestone

Initial campaign planning UI for multi-touch email acquisition, with hypothetical economics and non-live wave allocations. This repository must not be used to send live campaigns until licensing, consent, suppression, security and ESP integrations are implemented and validated.

## Start

`npm install` then `npm run dev`

## Notes

- GitHub repository currently public; switch to private for confidential work.
- Ghost is an optional content/publishing integration, not an approved third-party list deployment platform.
- No purchased audience uploads, live sends, secret keys, deposits, or call tracking yet.
